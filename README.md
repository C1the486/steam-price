# steam-price
Steam游戏各区价格查询工具（Steam regional price query tool）
# Steam 游戏价格看板
无需 API Key 的 Steam 游戏价格查询工具。

## 功能
- 搜索游戏名称或 Steam App ID
- 搜索并选择自己所在的国家或地区
- 查询当地 Steam 现价
- 查看各区价格快照和收录最低价

## 使用方法
1. 电脑安装 Python 3。
2. 下载本仓库中的「启动看板.py」。
3. 在文件所在目录打开终端，执行：

   python 启动看板.py

4. 浏览器会自动打开看板，输入游戏名称即可查询。
无需安装额外依赖，也不需要 MySQL 或 API Key。
使用期间请保持程序运行，关闭程序后将无法继续查询。

## 数据说明
- 当地现价来自 Steam。
- 各区价格快照和收录最低价来自 SteamRaw。
- 收录最低价不保证覆盖游戏发售以来的完整历史。
- 未覆盖的地区显示“暂无数据”。
- 查询需要联网，结果受数据源可用性影响。
